# ElectroMedos — E-commerce Website

ElectroMedos is an e-commerce web application for electronic and medical products.

## Features

- Product catalog and product details
- Product categories
- Product search and filtering
- Product sorting
- Responsive user interface

## Technologies

- React
- JavaScript
- HTML5 and CSS3
- Vite

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/FatimaBenSoftEng/ElectroMedos.git
cd ElectroMedos/frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal.
